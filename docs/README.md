## 命名规范

- 格式：`YYYY-MM-DD_HHMM_<主题>.md`
- 时间放在**文件名开头**，24 小时制，`HHMM` 为 4 位数字（如 `0215` 表示 02:15）
- 主题可为单词或复合词（用下划线连接大类与细分）
- 主题示例：
  - 单词类：`项目说明`、`部署笔记`、`架构调整`、`问题排查`、`接口文档`
  - 复合类：`功能实现_新标签页打开`、`问题排查_暗色页脚悬空`
- 完整示例：
  - `2026-07-31_0215_项目说明.md`
  - `2026-07-31_0222_功能实现_新标签页打开.md`

### 为什么用「时间开头 + 时分」而非序号

- **自动排序**：文件名以 ISO 日期 + 时分开头，`ls` / 文件管理器默认排序即生成顺序
- **无需维护计数**：不必记得"今天已经第几份了"，看时间即可
- **同分钟内多份**：罕见；若发生，可在主题前手动加 `a/b/c` 区分，如 `2026-07-31_0222a_...`
