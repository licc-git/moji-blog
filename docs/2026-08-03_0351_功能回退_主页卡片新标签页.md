## 一、回退内容

移除主页笔记卡片标题链接上的 `target="_blank" rel="noopener"`，恢复为**同页跳转**。

### 改动位置

[app/templates/blog/index.html](file:///home/licc/my_blog/app/templates/blog/index.html) 第 59-62 行，笔记卡片标题链接：

```html
<h3 class="card-title">
  <a href="{{ url_for('blog.detail', post_id=post.id) }}"
     class="stretched-link text-reset text-decoration-none">{{ post.title }}</a>
</h3>
```

即删除原先追加的 `target="_blank" rel="noopener"` 两个属性。

> 因卡片使用 Bootstrap `stretched-link`，整张卡片可点击区域也随之恢复为同页跳转。
