## 一、技术栈一览

| 层次 | 技术选型 | 说明 |
| --- | --- | --- |
| 依赖管理 | **uv** + `pyproject.toml` | Python ≥ 3.12；锁文件 `uv.lock` |
| Web 框架 | **Flask 3.x** | 严格遵循 Application Factory Pattern |
| ORM | **Flask-SQLAlchemy** | 驱动 PyMySQL，连接 MySQL |
| 认证 | **Flask-Login** | 仅单用户登录，无注册 |
| 表单 | **Flask-WTF** | CSRF 保护 + 文件上传校验 |
| 迁移 | **Flask-Migrate** | 预留（目前用 `flask init-db` 直接建表） |
| Markdown | **python-markdown** + **Pygments** + **MathJax** | extra/codehilite/toc/nl2br/sane_lists 扩展 |
| 大模型 | **OpenAI SDK** | 兼容 DeepSeek 与智谱 GLM |
| 前端 UI | **Bootstrap 5.3** + Bootstrap Icons | CDN 引入，`data-bs-theme` 切换日/夜模式 |
| 字体 | Playfair Display + Noto Serif SC（衬线）/ Inter + Noto Sans SC（无衬线） | 「编辑/生活派」气质 |
| WSGI 服务器 | **Gunicorn**（gevent worker） + Unix Socket | 生产环境部署 |
| 反向代理 | Nginx（推荐） | 转发到 `run/moji_blog.sock` |

## 三、应用工厂与蓝图

### 3.1 应用工厂 [app/__init__.py](file:///home/licc/my_blog/app/__init__.py)

`create_app(config_name=None)` 串起整个装配流程：

1. `load_dotenv()` 加载 `.env`（无论用 `flask run` 还是 gunicorn 都生效）
2. `Flask(__name__)` + `app.config.from_object(get_config(...))`
3. 确保 `UPLOAD_FOLDER` 存在
4. 初始化扩展：`db / migrate / login_manager / csrf`
5. 注册四个蓝图（见下表）
6. 注入上下文变量：`site_name`、`site_tagline`、`nav_categories`
7. 注册错误处理：403 / 404 / 413 / 500
8. 注册 CLI 命令 + `shell_context_processor`

### 3.2 蓝图一览

| 蓝图 | 模块 | URL 前缀 | 主要路由 |
| --- | --- | --- | --- |
| `auth_bp` | [app/auth/views.py](file:///home/licc/my_blog/app/auth/views.py) | `/` | `/login`、`/logout` |
| `blog_bp` | [app/blog/views.py](file:///home/licc/my_blog/app/blog/views.py) | `/` | `/`、`/drafts`、`/post/<id>`、`/new`、`/post/<id>/edit`、`/post/<id>/delete`、`/categories/new`、`/post/<id>/export`、`/preview` |
| `upload_bp` | [app/upload/views.py](file:///home/licc/my_blog/app/upload/views.py) | `/` | `/uploads/<path:filename>`、`/upload`、`/files` |
| `ai_bp` | [app/ai/views.py](file:///home/licc/my_blog/app/ai/views.py) | `/ai` | `/ai/actions`、`/ai/assist` |

> **硬约束**：所有蓝图路由文件统一命名为 `views.py`（不使用 `routes.py`），
> `app/__init__.py` 中的导入路径也必须保持一致。

### 3.3 权限策略

- 游客：可浏览已发布文章列表与详情、可下载导出文件
- 登录用户（管理员）： additionally 可写、编辑、删除、上传、调用 AI、查看草稿箱
- 未发布文章仅作者本人可访问，否则 404

## 四、数据模型 [app/models.py](file:///home/licc/my_blog/app/models.py)

```
User ─┬─< Post >── Category
      └─< UploadedFile
```

| 模型 | 关键字段 | 备注 |
| --- | --- | --- |
| `User` | username / email / password_hash / display_name / is_admin | 单用户；密码仅存哈希；通过 `flask init-admin` 创建 |
| `Category` | name / description / sort_order | 预置 8 个分类（学习笔记、编程开发、数学算法…） |
| `Post` | title / slug / summary / content_md / content_html / is_published / is_pinned / tags / view_count | **同时存 Markdown 原文 + 渲染缓存 HTML**；tags 用逗号分隔字符串 |
| `UploadedFile` | original_name / stored_name / relative_path / url / mime_type / size / extension / is_image | 实际文件落本地 `uploads/`，DB 仅存元数据 |

预置分类常量：`DEFAULT_CATEGORIES`、`CATEGORY_STUDY = "学习笔记"`、`CATEGORY_DAILY = "日常随笔"`。

## 五、关键功能说明

### 5.1 Markdown 渲染与导出 [app/utils/markdown_utils.py](file:///home/licc/my_blog/app/utils/markdown_utils.py)

- `render_markdown(text)`：扩展与配置从 `app.config` 读取，统一渲染
- `build_export_markdown(post)`：生成带 frontmatter 的 `.md`，含 title/category/date/updated/tags/summary
- 文章保存时**同步预渲染** HTML 入库，读取时零渲染开销
- 详情页与编辑页预览均通过 `/preview` 接口返回 HTML，前端再用 hljs / MathJax 排版

### 5.2 文件上传 [app/upload/views.py](file:///home/licc/my_blog/app/upload/views.py) + [app/utils/files.py](file:///home/licc/my_blog/app/utils/files.py)

- 扩展名白名单（`Config.ALLOWED_EXTENSIONS`）：图片 / 文档 / 压缩包 / 文本代码
- 单文件 ≤ 16MB（`MAX_CONTENT_LENGTH`，超限触发 413）
- **UUID 重命名**杜绝路径穿越；按 `images|files/<年>/<月>/` 分目录
- 上传后返回 JSON：`{ file: {...}, markdown: "![](url) 或 [name](url)" }`，编辑器自动插入
- 文件访问走 `/uploads/<path:filename>`，由 `send_from_directory` 内部 `safe_join` 防穿越

### 5.3 AI 助手 [app/ai/views.py](file:///home/licc/my_blog/app/ai/views.py) + [app/utils/ai_client.py](file:///home/licc/my_blog/app/utils/ai_client.py)

- 后端代理转发，**API Key 永不暴露到浏览器**
- 通过 OpenAI SDK 兼容接口同时支持 DeepSeek 与 GLM，由 `AI_PROVIDER` 切换
- 预设动作（`AI_ACTIONS`）：
  - `polish` 润色文章（temperature 0.5）
  - `summary` 生成摘要（temperature 0.3）
  - `continue` 续写（temperature 0.8）
- 也支持自由对话：`action=chat` + `messages`
- 接口：`GET /ai/actions`（列动作）、`POST /ai/assist`（执行）

### 5.4 编辑器前端 [app/static/js/editor.js](file:///home/licc/my_blog/app/static/js/editor.js)

- 左右分屏：左侧 textarea，右侧实时预览（350ms 防抖）
- 工具栏：上传图片 / 上传附件 / 润色 / 摘要 / 续写 / 新建分类
- 配置通过 `window.MO_EDITOR_CONFIG` 注入 URL，CSRF Token 自动携带
- Ctrl+S 保存、字数统计、AI 结果二次确认插入

### 5.5 首页筛选与侧栏 [app/templates/blog/index.html](file:///home/licc/my_blog/app/templates/blog/index.html)

- 支持 `category` / `q`（关键词）/ `tag` / `year` / `month` 组合筛选
- 置顶优先，再按创建时间倒序，每页 9 篇
- 侧栏：标签云（最多 30 个）+ 月份归档
- **双击选中项取消筛选**：通过 `data-clear-url` 实现（见下文约定）

## 七、运行与部署

### 7.1 首次初始化

```bash
# 1. 创建 MySQL 库与用户
mysql -u root -p < db_init.sql

# 2. 安装依赖
uv sync                        # 开发依赖
uv sync --extra prod           # 含 gunicorn 的生产依赖

# 3. 配置环境变量
cp .env.example .env           # 按需修改 SECRET_KEY / DB 密码 / AI Key / ADMIN_PASSWORD

# 4. 一键初始化数据库（建表 + 预置分类 + 管理员 + 示例文章）
uv run flask seed
```

### 7.2 开发模式

```bash
uv run flask run               # 监听 0.0.0.0:5099，--reload 自动启用
```

或直接：

```bash
uv run python wsgi.py
```

### 7.3 生产部署（Gunicorn + Unix Socket）

```bash
# 启动
uv run --extra prod gunicorn -c gunicorn.py wsgi:app

# 平滑重载（改代码后不中断服务）
kill -HUP $(cat run/gunicorn.pid)

# 停止
kill $(cat run/gunicorn.pid)
```

[gunicorn.py](file:///home/licc/my_blog/gunicorn.py) 关键参数：

- `bind = unix:<root>/run/moji_blog.sock`
- `workers = 4`，`worker_class = "gevent"`，`worker_connections = 1000`
- `max_requests = 1000` + `max_requests_jitter = 100`（防内存泄漏）
- 日志：`logs/gunicorn_access.log` / `logs/gunicorn_error.log`

Nginx 反向代理示例（上游指向 Unix Socket）：

```nginx
location / {
    proxy_pass http://unix:/home/licc/my_blog/run/moji_blog.sock:;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

### 7.4 常用 CLI 命令

| 命令 | 作用 |
| --- | --- |
| `uv run flask init-db` | 仅建表 |
| `uv run flask init-admin` | 创建/重置管理员 |
| `uv run flask init-categories` | 预置默认分类 |
| `uv run flask seed` | 一键初始化（推荐） |
| `uv run flask drop-db` | 删除所有表（危险，需确认） |

## 八、设计约定与硬约束

> 以下约定来自项目演进过程中沉淀的 [project_memory](file:///home/licc/.trae-cn/memory/projects/-home-licc-my-blog/project_memory.md)，
> 修改时请同步更新记忆文件。

### 8.1 工程约定

- **蓝图路由文件统一命名 `views.py`**，`app/__init__.py` 导入路径需一致
- Flask 开发服务器绑定 `0.0.0.0:5099`（通过 `.flaskenv` 配置）
- 模板自动重载（`TEMPLATES_AUTO_RELOAD = True`）+ `--reload` 模式
- CSS/JS 静态资源 URL 带 `?v=N` 版本号破缓存（当前 `style.css?v=3`、`main.js?v=2`）
- HTML 结构**禁止嵌套 `<a>`**（卡片用 Bootstrap `stretched-link` 实现整卡可点）

### 8.2 视觉风格（「编辑/生活派」）

- 背景：奶黄纸 `#faf6ee`（亮）/ 深墨棕 `#1a1612`（暗）
- 主色：赭石 `#b15a3c`（亮）/ 提亮赭石 `#d4795a`（暗）
- 字体：衬线 Playfair Display + Noto Serif SC（标题/正文），无衬线 Inter + Noto Sans SC（UI）
- 卡片固定高度（桌面 300px / 移动 260px）+ 内容截断
- 导航栏精简为 3 项，其余分类收纳进「更多」下拉
- 侧栏 sticky 定位 + 纸质质感
- 标签云：药丸形 chip，选中态赭石底

### 8.3 主题切换

- 通过 `<html data-bs-theme>` 切换，Bootstrap 组件自动适配
- `localStorage` 持久化（key：`moji-theme`），首次访问跟随系统偏好
- **防 FOUC**：`base.html` 头部内联脚本在首次渲染前应用主题
- 切换按钮图标：亮色显 🌙（`bi-moon-stars`），暗色显 ☀️（`bi-sun`）

### 8.4 筛选交互

- **不显示**「筛选状态条」式丑框，改用轻量提示行
- 提示文案：`🔽 标签「{tag}」· 双击选中项可取消筛选`
- 选中项带 `data-clear-url` 属性，指向不含该筛选的干净 URL
- **双击选中项 → 取消筛选**（250ms 延时区分单击/双击）

### 8.5 布局

- 亮/暗模式 `body` 均使用 flex 布局（`min-height:100vh` + `display:flex` + `flex-direction:column`）
- 确保 footer 始终贴底，即便正文内容很短
- 主内容区 `flex-grow-1` 撑开

### 8.6 CSS 规范

- **所有非显而易见的 CSS 必须带中文注释**说明用途
- 暗色模式样式集中在 `[data-bs-theme='dark']` 选择器下

## 九、常见排查入口

| 现象 | 排查位置 |
| --- | --- |
| 启动失败 / 配置不生效 | `.env` 是否存在、`FLASK_ENV` 值、[app/config.py](file:///home/licc/my_blog/app/config.py) |
| 数据库连接错误 | `DATABASE_URL`、`db_init.sql` 是否执行、MySQL 服务状态 |
| 上传失败 | `MAX_CONTENT_LENGTH`、扩展名白名单、`uploads/` 目录权限 |
| AI 调用失败 | `AI_PROVIDER` 与对应 `*_API_KEY`、[app/utils/ai_client.py](file:///home/licc/my_blog/app/utils/ai_client.py) |
| 样式不更新 | 静态资源 `?v=N` 是否递增、浏览器强刷 |
| 主题闪烁 | [base.html](file:///home/licc/my_blog/app/templates/base.html) 头部内联脚本是否被改动 |
| Footer 居中悬空 | `body` 是否同时具备 flex 三件套（亮/暗两套都要） |
| Gunicorn 进程异常 | `logs/gunicorn_error.log`、`run/gunicorn.pid` |
